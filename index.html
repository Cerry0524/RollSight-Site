基本使用流程

  1. 首次啟動設定 PIN，建立第一個單位或使用快速建立流程。
  2. 建立座位圖設定座位數、分區與人員配置，作為日常點名基礎。
  3. 執行點名建立點名任務，在座位圖或名冊中標記出席狀態。
  4. 匯出與同步產生報告圖片，或用 QR Code 傳送資料給另一台裝置。

隱私原則

RollSight 是離線優先工具。你建立的單位、人員、點名與座位圖資料儲存在裝置本機；跨裝置資料傳輸透過 QR Code 點對點進行。App 只使用匿名崩潰與效能資料來修復問題。
