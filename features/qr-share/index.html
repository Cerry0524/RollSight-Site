到齊 RollSight 的資料分享採使用者主動觸發。App 不會自動把點名資料送出去；需要交接時，才由使用者自行選擇產生 QR Code 或資料碼圖片。

WORKFLOW

分享流程

  1. 完成點名先在自己的手機完成點名、摘要整理或資料彙整。
  2. 產生資料碼由使用者主動選擇分享，產生 QR Code 或資料碼圖片。
  3. 自行傳送透過現場掃描、相簿圖片或既有通訊方式交給指定對象。
  4. 對方匯入對方掃描或讀取圖片後，才把資料匯入自己的裝置。
  5. 確認結果匯入後再檢查任務摘要、來源與重送差異。

資料分享原則
