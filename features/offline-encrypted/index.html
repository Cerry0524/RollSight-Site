OFFLINE SECURITY

離線點名與本機資料保護

到齊 RollSight 不是雲端點名系統。名冊、座位圖、點名任務與回報資料儲存在自己的手機中，適合需要現場快速作業、但不想把資料自動送到外部服務的使用情境。

WHY LOCAL

和雲端點名系統的差異

雲端系統通常把資料集中到伺服器，方便後台管理與跨裝置同步；到齊 RollSight 的重點則是本機作業、離線使用與自主分享。

DEVICE

資料放在自己的手機

建立單位、座位圖與點名任務後，主要流程可在本機操作。

PROTECTION

本機資料保護

本機資料具備保護設計，降低裝置遺失、借用或臨時交接時的資料風險。

CONTROL

分享由使用者決定

只有在需要交接時，才由使用者自行產生 QR Code 或資料碼圖片。
